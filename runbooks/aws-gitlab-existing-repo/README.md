# Bootstrap Gruntwork Pipelines — AWS + GitLab (existing repository)

A [Gruntwork Runbook](https://runbooks.gruntwork.io) that adds Gruntwork Pipelines (Terragrunt Scale) to
an **existing** GitLab `infrastructure-live` repository for one **AWS** account.

Open it with:

```bash
runbooks open ./runbooks/aws-gitlab-existing-repo
```

Or directly from the catalog:

```bash
runbooks open https://github.com/gruntwork-io/terragrunt-scale-catalog/tree/main/runbooks/aws-gitlab-existing-repo
```

Mirrors the official guide:
[Add Pipelines to an existing GitLab repository](https://docs.gruntwork.io/2.0/docs/pipelines/installation/addingexistinggitlabrepo).
