# Bootstrap Gruntwork Pipelines — Azure + GitLab (new repository)

A [Gruntwork Runbook](https://runbooks.gruntwork.io) that creates a **new** GitLab `infrastructure-live`
repository and bootstraps Gruntwork Pipelines (Terragrunt Scale) into it for one **Azure** subscription.

Open it with:

```bash
runbooks open ./runbooks/azure-gitlab-new-repo
```

Or directly from the catalog:

```bash
runbooks open https://github.com/gruntwork-io/terragrunt-scale-catalog/tree/main/runbooks/azure-gitlab-new-repo
```

Mirrors the official guide:
[Add Pipelines to a GitLab repository](https://docs.gruntwork.io/2.0/docs/pipelines/installation/addinggitlabrepo)
(Azure).
