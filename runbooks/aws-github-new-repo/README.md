# Bootstrap Gruntwork Pipelines — AWS + GitHub (new repository)

A [Gruntwork Runbook](https://runbooks.gruntwork.io) that creates a **new** GitHub `infrastructure-live`
repository, scaffolds it for Gruntwork Pipelines (Terragrunt Scale), and bootstraps one **AWS** account.

Open it with:

```bash
runbooks open ./runbooks/aws-github-new-repo
```

Or directly from the catalog:

```bash
runbooks open https://github.com/gruntwork-io/terragrunt-scale-catalog/tree/main/runbooks/aws-github-new-repo
```

Mirrors the official guide:
[Add Pipelines to a new repository](https://docs.gruntwork.io/2.0/docs/pipelines/installation/addingnewrepo).
