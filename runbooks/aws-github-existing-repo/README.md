# Bootstrap Gruntwork Pipelines — AWS + GitHub (existing repository)

A [Gruntwork Runbook](https://runbooks.gruntwork.io) that adds Gruntwork Pipelines (Terragrunt Scale) to
an **existing** GitHub `infrastructure-live` repository for one **AWS** account.

Open it with:

```bash
runbooks open ./runbooks/aws-github-existing-repo
```

Or directly from the catalog:

```bash
runbooks open https://github.com/gruntwork-io/terragrunt-scale-catalog/tree/main/runbooks/aws-github-existing-repo
```

Mirrors the official guide:
[Add Pipelines to an existing repository](https://docs.gruntwork.io/2.0/docs/pipelines/installation/addingexistingrepo).
